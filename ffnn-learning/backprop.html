Backpropagation

Backpropagation (Backward Propagation of Errors) is how neural networks learn. It calculates the gradient (slope) of the Loss Function with respect to every weight and bias in the network.

Key Concepts

Gradient Descent An optimization algorithm that moves weights in the opposite direction of the gradient to minimize loss.
Chain Rule A calculus rule used to calculate the derivative of a function formed by the composition of other functions.
Delta (δ) The "local error" of a neuron, representing how much its weighted sum (z) affects the total loss.
Learning Rate (η) A scalar that controls the size of the weight updates (step size).
Backprop Short for "Backpropagation of Error."

1. The Loss Function

We need a way to measure how "wrong" the network is. We use Mean Squared Error (MSE).

L = ½(target - output)²
Derivation: ∂L/∂a (Loss wrt Output) [Click to Expand]

We use the power rule to differentiate the MSE loss with respect to the output activation (a):

∂L/∂a = ½ * 2 * (a - target)¹ * (1)
∂L/∂a = (a - target)

2. The Chain Rule Step-by-Step

To find how much a weight w contributed to the error L, we break it into parts:

∂L/∂w = (∂L/∂a) * (∂a/∂z) * (∂z/∂w)
Full Derivation: Output Layer Weight Gradient [Click to Expand]

Part 1: How Loss changes with Output (∂L/∂a)

∂L/∂a = (a - target)

Part 2: How Output changes with weighted sum (∂a/∂z)

Since a = σ(z), we need the derivative of Sigmoid:

σ'(z) = a(1 - a)

Part 3: How weighted sum changes with Weight (∂z/∂w)

Since z = w * a_prev + b:

∂z/∂w = a_prev

Conclusion: The Output Delta (δ)

We combine Part 1 and Part 2 into a single term called Delta:

δ = (a - target) * a(1 - a)

Final Gradient:

∂L/∂w = δ * a_prev
∂L/∂b = δ * 1

3. Hidden Layer Gradients

Hidden layers don't have a "target." Their "error" is calculated by seeing how much they contributed to the error in the next layer.

δˡ = (transpose(Wˡ⁺¹) · δˡ⁺¹) * σ'(zˡ)
Step-by-Step: Hidden Layer Delta Derivation [Click to Expand]

Step 1: Propagate next layer's error backwards

Multiply the delta of the next layer (δˡ⁺¹) by the weights connecting current layer to next (Wˡ⁺¹). We use the transpose because we are moving backwards.

Step 2: Apply Activation Gradient

Multiply by the derivative of the current layer's activation function σ'(zˡ).

Step 3: Update Weights

Just like the output layer:

∂L/∂wˡ = δˡ * aˡ⁻¹

Why This Matters

Backpropagation is the engine of modern AI. Without it, we would have no way to "correct" the millions of parameters in a large network. It connects the high-level goal (reducing error) to the low-level mechanical updates of weights and biases.
