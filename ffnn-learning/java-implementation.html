Building a Neural Network in Java

Now that you understand the math, let's implement a Feedforward Neural Network from scratch in Java. We will not use any external libraries. We will build our own Matrix library first.

Translating Math Into Java

1. The Matrix Class

The Matrix class is the backbone of our implementation. It provides the low-level linear algebra needed to process entire layers of neurons at once. 

public class Matrix {
    double[][] data;
    int rows, cols;

    public Matrix(int rows, int cols) {
        this.data = new double[rows][cols];
        this.rows = rows;
        this.cols = cols;
    }

    // WHY: We need matrix multiplication for 'Wx' (weighted sum).
    public static Matrix multiply(Matrix a, Matrix b) {
        Matrix temp = new Matrix(a.rows, b.cols);
        for (int i = 0; i < temp.rows; i++) {
            for (int j = 0; j < temp.cols; j++) {
                double sum = 0;
                for (int k = 0; k < a.cols; k++) {
                    sum += a.data[i][k] * b.data[k][j];
                }
                temp.data[i][j] = sum;
            }
        }
        return temp;
    }

    // WHY: To add the 'b' (bias) to the weighted sum.
    public void add(Matrix m) {
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                this.data[i][j] += m.data[i][j];
            }
        }
    }

    // WHY: Non-linearity needed to solve complex problems.
    public void sigmoid() {
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++)
                this.data[i][j] = 1 / (1 + Math.exp(-this.data[i][j]));
        }
    }
}

Explanation: This class abstracts away the nested loops needed for matrix math. Instead of writing loops in our network logic, we just call multiply() and add().

2. The NeuralNetwork Class

The NeuralNetwork class connects the layers together. It holds the weights and biases and implements the logic for forward() and train(). 

public class NeuralNetwork {
    // Fields: Storage for the 'knowledge' (weights/biases)
    Matrix weights_ih, weights_ho, bias_h, bias_o;
    double learning_rate = 0.01;

    public NeuralNetwork(int i, int h, int o) {
        weights_ih = new Matrix(h, i); // Input to Hidden
        weights_ho = new Matrix(o, h); // Hidden to Output
        bias_h = new Matrix(h, 1);
        bias_o = new Matrix(o, 1);
    }

    public List<Double> forward(double[] input_array) {
        // Step 1: Input to Hidden
        Matrix inputs = Matrix.fromArray(input_array);
        Matrix hidden = Matrix.multiply(weights_ih, inputs);
        hidden.add(bias_h);
        hidden.sigmoid();

        // Step 2: Hidden to Output
        Matrix output = Matrix.multiply(weights_ho, hidden);
        output.add(bias_o);
        output.sigmoid();

        return output.toArray();
    }
}

Explanation: The constructor initializes weights randomly. The forward() method implements the "Forward Pass" we studied, calculating signals from left to right through the network.

3. XOR Training Walkthrough

The XOR Problem: Why it Needs Hidden Layers [Click to Expand]

A single neuron can only draw a straight line (Linear Classifier).

The XOR inputs are:

  • (0,0) → 0
  • (1,1) → 0
  • (0,1) → 1
  • (1,0) → 1

Try drawing a single straight line that separates the 0s from the 1s. It is impossible!

Hidden layers transform the input space, "warping" it so that the final layer can draw a line to separate the classes.

4. Debugging Common Implementation Mistakes

Dimension Mismatch

Problem: Matrix multiplication fails because cols_A != rows_B.

Fix: Print matrix dimensions before every multiplication. Remember: Weight matrix should be (next_layer_nodes, current_layer_nodes).

Wrong Gradient Formula

Problem: Training makes the loss go UP or stay flat.

Fix: Ensure you are using target - output and not output - target (or adjust the update sign accordingly).

Exploding Gradients / Learning Rate Too High

Problem: Weights become NaN or infinity.

Fix: Reduce learning_rate (try 0.1 or 0.01) and ensure weights are initialized to small values (e.g., between -1 and 1).
