Mathematical Foundations

To understand neural networks, you need to be comfortable with Linear Algebra and Calculus. This page covers the essential concepts: Vectors, Matrices, and Activation Functions.

Key Concepts

Neuron The basic unit of a neural network that receives inputs, processes them, and passes an output.
Weight A value that determines the strength of the connection between two neurons.
Bias An extra parameter that allows the activation function to be shifted left or right.
Activation A function that decides if a neuron should "fire" by introducing non-linearity.
Layer A group of neurons that operate together at a specific depth in the network.
Loss A metric that measures how far the network's prediction is from the actual target.
Gradient The direction and rate of fastest increase of the loss function.

1. Vectors & Matrices

A Vector is an array of numbers. In NN context, an input layer is a vector.
A Matrix is a 2D array of numbers. Weights connecting layers form a matrix.

The Core Equation:

z = W · x + b

Full Scalar Form (z = Wx + b) [Click to Expand]

When expanded into individual components, the weighted sum for a single neuron j in the next layer is:

zⱼ = (wⱼ₁ · x₁ + wⱼ₂ · x₂ + ... + wⱼₙ · xₙ) + bⱼ

In summation notation:

zⱼ = Σ (wⱼᵢ · xᵢ) + bⱼ
Numeric Matrix Multiplication Example [Click to Expand]

Let's calculate the weighted sum for 2 inputs and 1 neuron.

Given:

  • Input x = [0.5, 0.8]
  • Weights W = [0.2, 0.4]
  • Bias b = 0.1

Step 1: Dot Product (W · x)

(0.2 * 0.5) + (0.4 * 0.8) = 0.1 + 0.32 = 0.42

Step 2: Add Bias (+ b)

0.42 + 0.1 = 0.52

Result: z = 0.52

2. Activation Functions

Activation functions introduce non-linearity. Without them, a neural network is just a linear regression model, no matter how many layers it has. They decide whether a neuron should "fire" or not.

Sigmoid

Squashes values between 0 and 1. Useful for probability outputs.

σ(x) = 1 / (1 + e⁻ˣ)
σ'(x) = σ(x) * (1 - σ(x))

Output σ(x): 0.50 | Derivative σ'(x): 0.25

ReLU (Rectified Linear Unit)

Most common activation function. Computationally efficient.

R(x) = max(0, x)
R'(x) = 1 if x > 0 else 0

Output R(x): 0.00 | Derivative R'(x): 0

Why This Matters

The math on this page forms the "atomic" operations of AI. Matrix multiplication allows us to process thousands of connections simultaneously, while activation functions allow the network to learn complex, non-linear relationships in data. Understanding these basics is critical before looking at how data actually moves through the network.
